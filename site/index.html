Jury-like check on other data rows (seed 7, two runs per side): 88.2 s / 14 369 MiB vs 56.4 s / 3 145 MiB, so 1.56x faster and 4.57x lighter. The baseline's load time varies between Kaggle sessions, so single-run speedups of the same code ranged 1.55–1.74x; memory is deterministic.

The key finding

Triton 3.6 does not use the T4's tensor cores (sm_75, upstream issue triton-lang/triton#5066). Our first fused LM head with tl.dot was 9x slower than the baseline: 359 ms vs 15 ms for the same matmul in cuBLAS. So every matmul stays in cuBLAS, and Triton takes over everything around them.

Baseline profile: 44% of GPU time in element-wise ops and dtype casts, 7% in softmax/cross-entropy over a 151 936-token vocabulary (with gigabytes of fp32 logits), 5% in NF4 dequantization. Memory peaked at 14.3 of 15 GB.

The eight kernels

KernelReplaces / why
head_ce_rows_kernelThe full [tokens, vocab] fp32 logits + cross-entropy + entropy/accuracy metrics + per-row losses. Online softmax per row over 256-row chunks; the gradient is written over the chunk in place. The biggest memory win.
rmsnorm_fwd/bwd_kernelQwen2RMSNorm: ~6 PyTorch kernels per call, 57 norms per step, now one kernel each way; backward input kept in fp16.
nf4_dequant_kernelbitsandbytes' two-kernel NF4 double-quant dequantization, fused into one kernel for forward and backward of every 4-bit layer.
swiglu8_fwd/bwd_kernelSwiGLU MLP; the activations saved for backward are compressed to int8 with one fp32 scale per 64 values.
lora_dropout_fwd/bwd_kernelLoRA dropout on q/v projections over packed rows, using the baseline's RNG masks stored as bits; the whole LoRA branch is one autograd node.

Supporting changes without Triton: the decoder stack runs only on non-padding rows with one varlen attention call per layer, a lossless fp16 tied embedding (−933 MB), CPU–GPU syncs moved to the end of the step, and background kernel precompilation plus GPU warm-up while the model loads. The training task is unchanged: same model, data, batches, LoRA config, optimizer and outputs, verified by the organizers' rule checker.

Reproduce

Import templates/kaggle_notebook.ipynb into Kaggle, set Accelerator: GPU T4 x2 and Internet: on, then Run All (~10 minutes). It trains the baseline and the solution, evaluates both adapters and runs all checks.
